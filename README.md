# FM27 Face Studio

Football Manager 27 선수·스태프 얼굴 사진을 바꾸는 프로그램.

- 사진 자르기 편집기 (얼굴 자동 맞춤)
- 제미나이(나노 바나나) AI 사진 생성 — 참고 사진 함께 보내기 가능
- 대기열에 모아서 한 번에 적용 (graphics\FacePicker 폴더 + config.xml 자동 관리)
- 뉴젠·생성 인물 `r-` 접두사 처리, 다른 페이스팩과 충돌 검사
