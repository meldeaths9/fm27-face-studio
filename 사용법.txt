FM27 Face Studio v0.2 (1단계)
=============================

[처음 한 번]
1. 파이썬 설치: https://www.python.org/downloads/ 에서 Python 3.12 또는 3.13 권장
   - 설치 첫 화면 "Add python.exe to PATH" 꼭 체크
2. 이 폴더의 "설치.bat" 더블클릭
3. (선택) 배경 투명 기능이 필요하면 "배경제거_설치.bat" 더블클릭

[실행]
- "실행.bat" 더블클릭
- 창이 안 뜨거나 오류가 나면 "오류확인용_실행.bat"으로 실행해서 메시지를 알려주세요.

[사용 순서]
1. 대상 선택: 선수/스태프를 고르고 UID·이름 입력
   (2단계 플러그인이 나오면 이름·팀으로 검색해서 고를 수 있어요)
   - 뉴젠/생성 선수는 "뉴젠·생성 인물" 켜기 (UID가 20으로 시작하는 10자리면 자동으로 켜짐)
2. 사진 편집: 끌어다 놓기 / 클릭해서 고르기 / Ctrl+V 붙여넣기
   - 사진 위 드래그로 위치, 마우스 휠이나 아래 슬라이더로 크기, 더블클릭은 얼굴 자동 맞춤
   - AI로 만들기: 설정(톱니바퀴)에 제미나이 API 키를 넣고 "AI 생성"
     "현재 사진도 함께 보내기"를 켜면 그 사진 속 얼굴을 바탕으로 만들어요
3. "대기열에 추가" -> 여러 명 반복
4. "한 번에 적용" -> FM27을 완전히 껐다 켜면 반영

[저장 위치]
- 얼굴 사진과 config.xml: 문서\Sports Interactive\Football Manager 27\graphics\FacePicker
- 설정·대기열·config 백업: %APPDATA%\FM27FacePicker
- 이 프로그램은 FacePicker 폴더만 건드리고, 다른 페이스팩이나 게임 파일은 수정하지 않아요.

[얼굴이 안 바뀔 때]
- FM27을 완전히 종료 후 다시 실행했는지 확인
- "적용된 얼굴" 탭의 "충돌 검사": 다른 페이스팩이 같은 인물을 지정하면 그쪽이 우선될 수 있어요
- 뉴젠인데 뉴젠을 안 켰거나, 반대로 실존 선수인데 켰는지 확인

[제미나이 API 키]
- https://aistudio.google.com/apikey 에서 발급
- 키는 이 PC의 %APPDATA%\FM27FacePicker\settings.json 에만 저장돼요
